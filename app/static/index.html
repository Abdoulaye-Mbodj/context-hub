EXTENSION INDÉPENDANTE

Extension Context Hub pour Chrome / Edge

L’extension ne modifie jamais la navigation du Hub. Ouvrez-la depuis l’icône puzzle lorsque vous souhaitez contextualiser une page dans votre navigateur habituel.

Télécharger ne suffit pas à l’installer. Chrome interdit à une application web d’installer silencieusement une extension : elle n’apparaît dans la liste qu’après le chargement manuel ci-dessous.
  1. Téléchargez l’extension puis décompressez l’archive.
  2. Ouvrez chrome://extensions et activez le mode développeur.
  3. Choisissez « Charger l’extension non empaquetée » puis le dossier browser-extension.
  4. Dans l’icône puzzle, épinglez Context Hub. Version actuelle : 0.5.0.
