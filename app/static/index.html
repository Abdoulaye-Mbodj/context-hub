EXTENSION INDÉPENDANTE

Extension Context Hub pour Chrome / Edge

L’extension ne modifie jamais la navigation du Hub. Ouvrez-la directement depuis l’icône des extensions Chrome/Edge lorsque vous souhaitez afficher le panneau Context Hub à côté d’une application ouverte dans votre navigateur.

  1. Téléchargez l’extension puis décompressez l’archive.
  2. Ouvrez chrome://extensions et activez le mode développeur.
  3. Choisissez « Charger l’extension non empaquetée » puis le dossier browser-extension. Si elle est déjà installée, remplacez le dossier puis cliquez sur « Actualiser ».
  4. Épinglez l’icône Context Hub pour pouvoir ouvrir le panneau quand vous le souhaitez. Version actuelle : 0.4.1.
